# 02 – AWTRIX NG

[AWTRIX NG](https://github.com/Blueforcer/awtrix-ng) is the successor of AWTRIX 3 (AWTRIX 3 is archived).
No cloud, HTTP and MQTT API, Home Assistant MQTT discovery, Berry scripts running on the clock.

1. Back up the original firmware first ([00](../00_backup_original_firmware/)).
2. Flash from the browser (Chrome/Edge): <https://blueforcer.github.io/awtrix-ng/getting-started/flashing/>
3. Join the clock's setup hotspot and enter Wi-Fi: <https://blueforcer.github.io/awtrix-ng/getting-started/first-boot/>
4. Enter the MQTT broker for Home Assistant discovery.
5. Scripts, icons, automations: <https://awtrix.de>
